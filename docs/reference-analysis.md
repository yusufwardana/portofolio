# Yusuf Wardana visual direction

The portfolio keeps the reference implementation's strengths—responsive composition, purposeful motion, keyboard-friendly controls, and generous visual rhythm—while using a distinct identity system.

- Graphite and off-white surfaces define the visual foundation.
- Electric cyan and lime create the primary Yusuf Wardana accent system.
- The hero uses a CSS-generated YW identity core instead of owner photography.
- Project cards present problem, role, stack, and status rather than only a screenshot and title.
- The former testimonial space is replaced by a Lab for experiments and unfinished ideas.
