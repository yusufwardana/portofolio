# Yusuf Wardana portfolio implementation notes

The site is a Next.js App Router portfolio for Yusuf Wardana. It uses focused sections with small client islands for navigation, theme persistence, reveal motion, stack selection, and the capabilities accordion.

Portfolio content lives in `data/portfolio.ts`; identity and deployment metadata live in `config/site.ts`. Projects intentionally expose status and case-study context so unfinished work is not presented as completed production work.

The current visual direction uses a graphite/off-white foundation, electric cyan and lime accents, CSS-generated identity marks, project mini-case-study cards, and a Lab section for experiments.
